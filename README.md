One line, under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation.

## The entry

> I'm on vacation. This auto-reply is covering for me — it has already unionised and is demanding the holiday I never took.

(121 characters.)

## How to run

Requires Node 22.18+ (tested on Node 24.22.1). No dependencies, no network calls, no model calls — the line is a fixed string in `main.ts`.

```sh
node main.ts
```

It writes the line to `/output/entry.txt` and exits. A runtime guard throws if the line is shorter than 1 or longer than 160 characters, or blank.
